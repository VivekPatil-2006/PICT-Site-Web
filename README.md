# User Auth App

A simple Angular app with user registration, login, and profile display.

## Features

- 📝 **Register** - Create new user accounts
- 🔐 **Login** - Authenticate with email and password  
- 👤 **Profile** - View your profile information
- 💾 **LocalStorage** - Data persists across sessions

## Quick Start

```bash
npm start
```

Open `http://localhost:4200/` in your browser.

## Project Structure

```
src/app/
├── app.component.ts
├── app.module.ts
├── auth.service.ts
├── register.component.ts
├── login.component.ts
└── profile.component.ts
```

## How to Use

1. **Register** - Go to `/register`, fill in name, email, password
2. **Login** - Go to `/login`, enter your credentials
3. **Profile** - View your info on `/profile`
4. **Logout** - Click logout button in navbar
