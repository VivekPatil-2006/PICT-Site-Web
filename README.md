# PICT Academic Portal

The PICT Academic Portal is a responsive web-based academic information system designed to present institutional details, department toppers, assignment information, and academic performance statistics in a clean and user-friendly interface.

## Features
- Responsive layout using Bootstrap 5
- Section-based navigation with smooth scrolling
- Department toppers showcase using card layout
- Academic performance visualization using Chart.js
- Clean and professional academic UI design

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- Chart.js

## Use Case
This project can be used as a front-end prototype for academic institutions to display academic achievements, analytics, and structured information in a centralized portal.
